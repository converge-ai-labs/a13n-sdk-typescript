# Resources and Client Lifetime

`createClient({baseUrl,auth,fetch?,maxReadRetries?})` creates one transport. Bearer authentication accepts a token or asynchronous token callback; an API key selects its implicit workspace for ordinary business routes. Same-origin session authentication selects `workspaceId` explicitly and requires `X-CSRF-Token` for protected mutations (`setCsrfToken`), excluding the documented public auth/invitation flows. The SDK injects `X-Workspace-ID` only on operations declaring workspace scope. `setWorkspaceId` changes session scope; a conflicting explicitly selected scope raises rather than being silently overridden. Public, deployment-wide and organization-admin requests are not given a workspace header by default. There is no credential discovery, automatic login or cross-origin credential dispatch. `client.close()` aborts local work, not a remote Run.

`client.resources` provides a complete statically generated route tree. Literal segments use camelCase properties; path parameters use synchronous `.ref(value)` with declared types and one-time encoding. Each generated operation exposes only its declared verb and typed body, query and headers; collection pagination and byte ownership are generic adapters. Generated resources do not add handmade Agent waits or decoded persistent Thread event workflows. The authored Agent/Interaction/Run layer delegates to these same generated routes and typed SSE parser. There is no separate public `client.http` facade or another business tree.

JSON calls return `ResourceResult<T>` with `{data,response}` for status, ETag and request ID. Binary and raw SSE calls return an unbuffered owned `{body,response,close()}`. `ApiError` retains Service status/code/details, while invalid response interpretation raises `ProtocolError`. Fields preserve omission and explicit null. Options use camelCase `query`, `ifMatch`, `idempotencyKey`, and declared `xWorkspaceId`; wire bodies retain generated names. Conditional edits require their resource's ETag, except Memory file restoration when the target is absent. HTTP reads may retry boundedly; mutations dispatch once because a lost acknowledgement does not prove rollback.

`pages()` yields fresh page responses and `items()` flattens cursor collections; repeated next cursors fail. Resource references are not remote caches. Iteration, downloads, interactions and the client have separate local lifetimes. Closing a byte body or interaction never closes the client or mutates Service execution.
