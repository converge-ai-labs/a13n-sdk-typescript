# Resources and Client Lifetime

`createClient({baseUrl, auth, fetch?, maxReadRetries?})` creates one HTTP transport. Authentication is explicit: Bearer token (value or asynchronous callback) or same-origin browser session. Session mutations require a CSRF token restored with `setCsrfToken` and sent in `X-CSRF-Token`; the documented public auth and invitation routes are exempt. There is no ambient workspace header, public anonymous auth mode, environment credential discovery, automatic login, or request to another origin. `client.close()` aborts local pending work; it does not interrupt a remote Run.

`client.resources` provides the complete generated route tree. Literal segments use camelCase properties; path parameters use `.ref(value)` with the declared string, enum or numeric type. Binding is local and encodes each selector exactly once. Methods expose only declared verbs; leaf POST actions are named methods rather than arbitrary runtime dispatch. JSON methods return `ResourceResult<T>`, while binary and raw SSE methods return an owned `BinaryResult` whose body must be consumed or closed. Generated query options are typed under `query`; supported headers use camelCase options. Header optionality follows OpenAPI, not a claim that the Service permits an omitted conditional precondition. Existing managed conveniences retain their stricter ETag options.

The raw `http` client uses generated OpenAPI paths. `workspaceHttp(workspaceId)` binds only the workspace path prefix, never a workspace inferred from credentials. `client.workspaces.ref(id)`, `client.organizations.ref(id)` and child `ref(id)` factories are synchronous, local references. The Service authorizes every request against its path identity. No handle is an active-record cache.

Managed reads return `{data, response}` so status, ETag, request IDs and other headers remain available. An HTTP error raises `ApiError` with the Service error evidence. A missing required representation raises `ProtocolError` through `data(...)`; the SDK does not invent one for 204. Query filters and JSON bodies preserve field omission and explicit null. The caller supplies idempotency keys on replay-safe submission endpoints and `If-Match` on conditional edits. HTTP reads may retry boundedly; mutations are dispatched once because a lost acknowledgement does not prove the mutation did not commit.

Pages expose one fresh `{data,response}` per pull. `items()` flattens them for convenience; use `pages()` when cursor/response evidence matters. Repeated next cursors fail instead of looping. The iterator, binary body, Thread stream and client have independent local lifetimes. Closing a stream does not close the client or mutate Service state.
